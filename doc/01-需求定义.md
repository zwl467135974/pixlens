# 01 需求定义

> 状态：已定稿 | 决策日期：2026-09-20
> 本文档是 PixLens（图镜）的需求基线，后续设计与实施以本文为准。

## 1. 产品定位与原则

做一个 **Windows 桌面端免费看图软件**，对标市面上收费、功能残缺、广告泛滥的看图工具。

核心原则（不可妥协）：

| 原则 | 说明 |
|---|---|
| 完全免费 | 无付费墙、无内购、不拆分"专业版"功能 |
| 无广告 | 不展示任何广告，不捆绑推广 |
| 本地优先 | 纯本地处理，不联网、无遥测、无账号 |
| 轻快 | 安装包小、启动快、占用低，对标 ACDSee / IrfanView 的轻快感 |
| 功能实在 | 缩略图浏览 + 极速看图 + PSD/PSB 支持 + 批量处理 + 基础编辑 |

## 2. 目标平台

- **Windows 10 / 11，x64**（唯一目标平台）
- 明确不做 macOS / iOS / Linux（无对应环境，v1 不投入）
- 技术选型保留未来跨平台可能性（见《02-技术选型》），但不作为需求承诺

## 3. 目标用户

- 需要浏览大量图片的普通用户（照片库、素材库）
- 需要**直接查看 PSD/PSB 设计源文件**的设计师（不启动 Photoshop 快速看稿）
- 讨厌广告与臃肿软件、追求轻快工具的用户

## 5. 功能需求

### F1 缩略图浏览（v1 核心）

- 打开文件夹，扫描全部图片文件，网格缩略图墙展示
- 虚拟滚动：单文件夹上万张图片滚动不卡
- 缩略图尺寸可调（滑块，约 96px ~ 512px）
- 排序：文件名（自然排序）/ 修改时间 / 大小 / 类型，升序降序
- 搜索：按文件名即时过滤
- 磁盘缩略图缓存：二次打开同一文件夹秒出图
- 文件夹内容变更自动刷新（新增/删除/重命名）

### F2 极速大图浏览（v1 核心）

- 缩放：滚轮（以光标为中心）、按钮、双击切换 适应窗口/100%
- 平移：拖拽
- 旋转（左右 90°）、水平/垂直翻转
- 翻页：上一张/下一张，键盘方向键，相邻图预加载
- 全屏幻灯片：可设间隔（2/5/10 秒）
- GIF 动图播放
- 完整键盘快捷键（基线如下，实施时可微调）

| 按键 | 功能 |
|---|---|
| ← / → | 上一张 / 下一张 |
| 滚轮 | 缩放（查看器内） |
| +/- / 0 / 1 | 放大 / 缩小 / 适应窗口 / 100% |
| R / L | 向右 / 向左旋转 |
| F | 全屏 |
| 空格 | 幻灯片 播放/暂停 |
| I | 图片信息面板 |
| Esc | 关闭查看器 |

### F3 格式支持矩阵

| 格式 | 缩略图 | 大图查看 | 批量转换输出 | 技术路径 |
|---|---|---|---|---|
| JPG / PNG / GIF(动图) / WebP / BMP / ICO | ✅ | ✅ | ✅ | Rust `image` 解码 |
| AVIF / SVG | ✅ | ✅ | — | WebView2 原生解码（字节透传） |
| **PSD / PSB** | ✅ | ✅ | — | **自研 Rust 解析器**，详见《03-架构设计》§6 |
| TIFF（多页） | ✅ | ✅ 翻页 | ✅ | `image` + 多页扩展处理 |
| HDR（32 位） | ✅ | ✅ 基础色调映射 | — | 简单曝光/Reinhard 映射，v1 不追求专业级 |
| RAW（CR3/NEF/ARW/DNG…） | — | — | — | **backlog**，v2 候选 |

### F4 批量处理（v1）

- 批量重命名：序号 / 原名 / 日期 组合模板，实时预览
- 批量格式转换：JPG / PNG / WebP 互转，质量可调
- 批量压缩：按目标质量
- 批量缩放：按最长边 / 百分比
- 进度条 + 可取消；处理后保留原图（输出到子目录或覆盖，用户可选）

### F5 基础编辑（v1）

- 裁剪（框选 → 保存）
- 旋转/翻转后保存
- 亮度 / 对比度 / 饱和度调节（实时预览 → 保存）
- 简单滤镜预设（灰度/复古等，不做专业修图）

## 6. 非功能需求

- 性能：见《04-性能要求》，为验收标准而非软性目标
- 隐私：不联网（不做更新检查）、无遥测、无账号
- 稳定：损坏文件/超大文件不崩溃，解码失败显示占位图标并继续可用
- 卸载干净：缓存目录可随卸载清理

## 7. 明确不做（v1 范围外）

- RAW 格式（v2 候选）
- EXIF 信息面板（v1.x 增强，工作量小）
- 图片标注/水印、图层级 PSD 编辑、色彩管理（ICC）
- 非 Windows 平台、在线相册/云同步

## 8. Backlog（按优先级）

1. EXIF 信息面板（相机参数、GPS）
2. RAW 格式支持（libraw / rawler 集成）
3. JPEG 无损旋转（jpegtran 方案）
4. 双图对比视图、收藏/评分
5. 色彩管理（ICC profile）
6. 跨平台（macOS/Linux）评估
