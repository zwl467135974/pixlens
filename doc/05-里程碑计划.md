（P 编号见《04-性能要求》§1）

## M1 工程骨架与缩略图墙

**范围**：
- 执行《02-技术选型》§6 前置检查（MSVC / WebView2），通过后初始化 Tauri 2 工程（Rust + Vite + TS 无框架）
- `scan_folder` 命令：walkdir 扫描 + 扩展名白名单 + 元数据返回
- `thumb://` 自定义协议：解码 → 缩放 → JPEG → 磁盘 LRU 缓存（含信号量限流）
- 前端：空态页（打开文件夹）、虚拟滚动缩略图墙、排序（名称自然序/时间/大小/类型）、文件名搜索、缩略图尺寸滑块、状态栏计数
- notify 文件夹监听 + 增量刷新
- tests/：合成图库生成脚本（LIB-S、LIB-M）

**验收**：P2（10k 扫描 <2s）、P3（首屏 <500ms）、P4（滚动 60fps）、P5（二次打开秒出）

## M2 大图查看器

**范围**：
- Canvas 查看器：滚轮缩放（光标为中心）、拖拽平移、双击 适应/100%、旋转、翻转
- 翻页 + 预取（±2 张内存 LRU）、方向键/空格/Esc 等完整快捷键
- 全屏幻灯片（2/5/10s 间隔）、GIF 动图播放
- `image://` 整帧协议：降采样预览 → 100% 时全量替换（LOD）
- 信息面板（文件名/尺寸/大小/格式；EXIF 属 backlog 不做）

**验收**：P6（翻页预取 <16ms）、P7（50MP 平移 60fps）

## M3 PSD/PSB 解析器（头号特色）

**范围**：
- `codecs/psd.rs` 按《03-架构设计》§6 实现：头部校验、段跳过、1036 内嵌缩略图快路径、Raw/RLE 合成图解码、PSD/PSB 统一（u32/u64 长度差异）、mmap + rayon 并行
- 颜色模式：RGB/灰度 + Alpha；其余模式占位提示
- 深度 16/32 归一化（32 位基础曝光映射）
- 护栏：尺寸/像素上限、行表交叉校验、损坏文件不崩溃
- 单元测试：程序构造 PSD/PSB 样本（Raw+RLE × PSD+PSB × 多深度）往返验证；`thumb://` 与查看器接入

**验收**：P8（2GB PSB：内嵌缩略图 <100ms、合成预览 <2s）；损坏样本全通过占位不崩溃

## M4 多页 TIFF 与 HDR

**范围**：
- 多页 TIFF 解码 + 查看器翻页（页数显示、页间切换）
- 32 位 HDR 基础色调映射（线性→sRGB + 曝光滑块）

**验收**：LIB-TIFF 图库翻页流畅；HDR 文件可看且曝光可调

## M5 批量处理

**范围**：
- 重命名（模板：{原名}{序号}{日期}，实时预览、冲突检测）
- 格式转换（JPG/PNG/WebP + 质量）、压缩、缩放（最长边/百分比）
- 批量选择交互（Ctrl/Shift 多选）、进度条 + 取消、输出目录策略

**验收**：1 万张批量转换无卡死、可取消、进度准确；重命名预览与结果一致

## M6 基础编辑

**范围**：
- 裁剪（框选 + 保存）、旋转/翻转保存
- 亮度/对比度/饱和度实时预览 + 保存
- 简单滤镜预设；另存副本为默认，可覆盖

**验收**：编辑后图片正确落盘、原图默认保留；预览与成品一致

## M7 发布工程与终验

**范围**：
- 应用图标（`tauri icon` 全套）、NSIS 安装器（含 WebView2 引导）
- 文件关联：.psd .psb .tif .tiff .jpg .png .gif .webp .bmp .avif .svg（安装器注册，可勾选）
- 设置页：缓存上限（256MB~8GB）、默认排序、主题（深/浅）
- 卸载清理缓存目录
- 全量 12 项性能指标终验 + 结果归档

**验收**：P1~P12 全部达标；干净虚拟机安装→关联→双击打开 PSD 成功
