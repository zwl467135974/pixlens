# 02 技术选型

> 状态：已定稿 | 决策日期：2026-09-20

## 1. 候选方案对比

| 维度 | Tauri 2 ✅（选定） | Electron | Python + PySide6 |
|---|---|---|---|
| 安装包体积 | ~10-15MB | ~85-100MB | ~80MB+ |
| 常驻内存 | 60-120MB | 200-350MB | 150-250MB |
| 冷启动 | 快 | 中 | 慢（1-2 秒） |
| PSD/PSB 路线 | 自研 Rust 解析器：mmap + rayon 并行，GB 级文件不吃亏 | ag-psd（成熟纯 JS 库）；超大文件受 JS 内存模型限制 | 无成熟库，需绑定 C 库（libpsd 等年久失修） |
| CPU 密集解码 | Rust 原生多线程 | JS 单线程/Worker，重负载慢 5-10 倍 | Qt C++ 底子，可行 |
| UI 现代感 | WebView，HTML/CSS 自由发挥 | 同左 | QSS 打磨成本高 |
| 本机环境就绪度 | Rust ✅ Node ✅ | Node ✅ | Python ✅ |
| 许可证 | MIT / Apache-2.0 | MIT | LGPL（需注意动态链接合规） |

## 2. 决定

**Tauri 2（Rust 核心 + WebView2 界面）**，理由：

1. **轻快定位匹配**：10MB 级安装包、百兆内内存，是"免费轻快看图软件"产品身份的一部分
2. **PSD/PSB 高性能解码**：Rust 侧 mmap 零拷贝 + rayon 并行解码，PSB 大文件（GB 级）场景明显优于 JS 方案
3. **本机工具链已就绪**：Rust 1.97 + Node 22 均已安装，无需额外环境投入
4. **许可干净**：MIT/Apache 双许可，免费分发无障碍
5. **保留跨平台可能**：未来若做 macOS/Linux，前端与 Rust 核心可复用

### 前端框架决策：**无框架（vanilla TS）**

理由：本应用以 Canvas（缩略图墙、大图查看器）为主体，DOM 面板简单；无框架 = 包体最小、无虚拟 DOM 开销、零框架升级负担。

## 4. 关键技术路线决策

| 决策点 | 结论 | 理由 |
|---|---|---|
| PSD/PSB 解析 | **自研 Rust 解析器** | ag-psd 是 JS 库（性能受限）；libvips/ImageMagick 绑定体积大、许可与构建链复杂；PSD/PSB 合成图解码规范公开且边界清晰（见 03 文档 §6），自研可控、无重依赖 |
| AVIF / SVG 解码 | 走 WebView2 原生解码 | 避免集成 AVIF C 库（Windows 构建链复杂）；WebView2 (Chromium) 原生支持，`thumb://` 协议透传原始字节 |
| 缩略图传输 | 自定义协议 `thumb://` 直出 JPEG | 浏览器并发加载天然背压；避免走 JSON IPC 序列化大块二进制 |
| 16/32 位深 PSD | v1 归一化到 8 位显示；32 位做基础曝光映射 | HDR 专业色调映射放 M4+ |

## 6. 开工前置检查清单（M1 第一步执行）

> 设计阶段**尚未验证**以下两项，M1 会话必须先跑通再写代码。

**① MSVC 链接器**（Tauri 在 Windows 构建的硬性依赖；rustc 若为 gnu 工具链则需切换）：

```bash
rustup show   # 确认默认目标为 x86_64-pc-windows-msvc
"/c/Program Files (x86)/Microsoft Visual Studio/Installer/vswhere.exe" \
  -products '*' -requires Microsoft.VisualStudio.Component.VC.Tools.x86.x64 \
  -property installationPath
# 有安装路径输出 = OK；无输出 → 需安装 VS Build Tools（勾选"使用 C++ 的桌面开发"）
```

**② WebView2 运行时**（Tauri 前端容器；Edge 已装则大概率已具备）：

```bash
reg query "HKLM\SOFTWARE\WOW6432Node\Microsoft\EdgeUpdate\Clients\{F3017226-FE2A-4295-8BDF-00C3A9A7E4C5}" //v pv
```

**③ 预期说明**：首次 `cargo build` 需编译约 500 个 crate，耗时 3-10 分钟属正常；之后增量构建在几十秒内。

## 7. 风险与备选

| 风险 | 应对 |
|---|---|
| MSVC 工具链缺失 | 安装 VS Build Tools（约 6-8GB），或最后手段转 Electron 路线（架构文档的模块设计大部分仍适用） |
| `image` crate 某格式能力不足（如多页 TIFF） | 降级到 `tiff` crate 直接使用，接口已在解码层隔离 |
| 自研 PSD 解析器遇到冷门样本 | 保留 ag-psd（JS）作为 WebView 侧后备解码路径；积累失败样本驱动修复 |
| WebView2 行为差异（老版本 Win10） | NSIS 安装器捆绑 WebView2 引导安装 |
