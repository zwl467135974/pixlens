## ✨ 为什么选择 PixLens

### 1. 设计师友好：原生 PSD / PSB 支持

不用启动 Photoshop，双击就能看设计稿。市面上的免费看图软件几乎都不支持 PSD——我们**自研了完整的 PSD/PSB 解析引擎**（Rust 实现），覆盖真实世界的全部形态：

- 🖼️ **资源管理器里直接显示 PSD/PSB/视频 缩略图**（安装即生效，不装 Photoshop 也有预览）——从真实 Photoshop 文件到游戏管线工具导出的"PSB"，从 CMYK 印刷稿到 640MB 大资源段文件、2GB 超大文件全覆盖；**MP4/MOV 等视频同样有缩略图**（纯净系统不装任何播放器/解码套件也出图），卸载时自动还原系统默认处理
- ⚡ 大文件不等待：2GB PSB 内嵌缩略图 23ms 出图；合成预览采用**跨步采样 + 流式按需读取**——只解码需要的行、只读取命中的字节，文件再大内存也有界
- 内嵌缩略图快路径 + 合成图解码双引擎，损坏文件全程护栏不崩溃

## 📦 安装

1. [下载](https://gitee.com/wyler_admin/pixlens/releases) `PixLens_x64-setup.exe`（2.7MB）双击安装
2. 安装时可选：**"为所有用户安装"（推荐）**——缩略图扩展写入机器级注册，兼容性最好（会弹一次管理员确认）；"仅为我安装"保持轻量用户级
3. **系统要求**：Windows 10/11 x64（WebView2 一般系统自带）
4. 首次运行如遇 SmartScreen 提示"已保护你的电脑"：点**更多信息 → 仍要运行**（个人开发者未购买代码签名证书）

> PSD/PSB 缩略图预览安装后即生效。**从旧版本升级**：若之前缩略图显示异常，安装新版后清一次缩略图缓存（磁盘清理 → 勾选"缩略图"）——Explorer 会记住旧的失败结果。遇到环境问题的排查可使用仓库 `dist-diag` 诊断修复工具。
>
> .jpg 等常见格式如需设为默认打开方式：右键 → 打开方式 → 始终选择 PixLens（Windows 对常见格式有防篡改保护，任何软件都需要用户手动确认一次）。

## 🏗️ 技术架构（开发者向）

Tauri 2（Rust 核心 + WebView2 界面，TypeScript 无框架前端），几处值得一提的设计：

- **自研 PSD/PSB 解析器**（`crates/psd-codec`）：PSD/PSB 统一处理，**布局自适应解析**（真实世界的段长宽度形态多变，按结构锚点甄别）、mmap 零拷贝 + rayon 行级并行、**跨步行采样**让 2GB 文件只解 1/144 的数据就出预览、损坏文件全程护栏不崩溃
- **Explorer 缩略图扩展**：C++ COM 壳 + Rust 解码核心（独立 cdylib）+ 系统 GDI+，三层各司其职；流式初始化（2MB 头 + IStream seek 回调按需采样）让任意大小文件都有界内存——这条路踩过的坑全部记录在 `doc/06-经验沉淀.md`
- **数据通道设计**：像素字节走自定义协议（`thumb://` / `image://`），JSON IPC 只走小控制消息；Canvas 位图渲染 + 定容 LRU 保证万张滚动内存有界
- **性能即验收**：12 项性能指标全部有自动化基准（`PIXLENS_BENCH` 验收模式），每次改动跑回归，指标即文档

## 🛠️ 从源码构建

```bash
pnpm install                                # 前端依赖
pnpm tauri dev                              # 开发运行
cargo build -p psd-capi --release           # Rust 解码 cdylib（输出 pixlens_psd.dll）
cmd /c shell-thumb-cpp\build.bat            # C++ 缩略图 COM DLL
pnpm tauri build                            # NSIS 安装器（含缩略图扩展）
cargo test                                  # 单元测试
```
